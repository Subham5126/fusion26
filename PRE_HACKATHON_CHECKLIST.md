# Pre-Hackathon Checklist

Fusion Hackathon 2026 • October 9–10, 2026

Preparation only: no project idea or application stack is selected. Mark conditional items as not applicable until decisions or event rules are available.

## Repository and Team

- [ ] Repository ready; templates reviewed.
- [ ] Team members have repository access.
- [ ] Everyone cloned repository.
- [ ] Git installed.
- [ ] Git identity configured.
- [ ] IDE/editor ready.
- [ ] Runtime/tools installed after stack selection; verify existing tools beforehand.
- [ ] Git branch workflow tested.
- [ ] Everyone can create branches.
- [ ] Everyone can push their feature branches.
- [ ] Everyone understands PR workflow.
- [ ] `dev` branch created.
- [ ] `main` protected if appropriate, with PR review and applicable checks.
- [ ] `.env` ignored and `.env.example` tracked in the first reviewed commit.
- [ ] No secrets committed.
- [ ] GitHub secret scanning/push protection checked for availability and enabled where available.
- [ ] Communication channel ready; private security reporting contact set in SECURITY.md.

## Equipment and Accounts

- [ ] Internet/hotspot backup considered.
- [ ] Chargers/power banks ready.
- [ ] Required accounts created as requirements become known.
- [ ] Deployment accounts ready after selecting the provider.
- [ ] API provider accounts ready if required by the selected solution.

## Documentation and Demo

- [ ] Presentation template ready.
- [ ] Demo recording method ready.
- [ ] Screen recorder tested.
- [ ] README template ready.
- [ ] Architecture template ready.
- [ ] PS analysis template ready.
- [ ] Task division template ready.
- [ ] Submission requirements checked when announced, including deadline/timezone, allowed tools, AI rules, and IP/licensing requirements.

Use [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow and [docs/HACKATHON_PLAN.md](docs/HACKATHON_PLAN.md) for execution after receiving the PS.
