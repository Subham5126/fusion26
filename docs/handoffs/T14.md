## Contract consumed / boundary produced

Consumed: shared v0.1.0 coordinate conventions and existing
`app.schemas.result.Detection`; official ESA dataset/submission format plus
starter notebook examples. Local image-only Sequence contains frame_index 0..4,
original frame 1..5, unchanged grayscale pixels and unknown timestamps None.
It is not a replacement public SequenceInput. Labels are an explicit separate
immutable AnnotationSet, preserving original sequence ID type and raw fractional
x/y. Official inclusive half-pixel edge bounds are preserved without shift or
rounding. Array order does not establish object identity or visibility.

Produced: bounded local ZIP inventory (no payload reads), directory/ZIP sequence
loader, strict point-label parser, five-panel GT overlay and image-only Detector
Protocol. The detector is **not implemented**. The local CLI is unrelated to
future HTTP upload enforcement. No label/path fields were added to public contracts.

  concurrent malicious replacement of local directory files is outside scope.
