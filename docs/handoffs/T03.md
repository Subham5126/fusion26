## Implemented algorithms and consumed contracts

Reuses the existing loader, parser, overlay, FrameContext/Detector interface and
integration-owned `app.schemas.result.Detection` v0.1.0 without modifying them.
The main detector applies dtype-range grayscale normalization, mild Gaussian
denoising, broad Gaussian background subtraction, a compact-source difference
response, global MAD/local clipped RMS noise estimation, adaptive thresholding,
8-connected components, weighted centroid/box and area/elongation filtering.
Finite heuristic score: `(1-exp(-peak_snr/8))/max(1,elongation)`; not a probability.
Native raw x/y pixel coordinates are preserved with exclusive-upper boxes.
No axis swap, half-pixel shift, resizing, registration or truth access occurs.

Minimal comparator: median/MAD global threshold with shared component extraction,
broader area/elongation limits, same cap and development-only threshold tuning.
Matching is separate evaluation: explicit unmatched options, inclusive 5-pixel
gate, maximum valid one-to-one cardinality followed by minimum total distance.
This is per-frame localization scoring, not tracking or the official ESA score.
Undefined ratios/localization are null with reasons, and predictions never count
as new observations.

## Actual development and held-out benchmark

Seed 26 uniformly sampled whole sequences, 24 official train sequences (120
frames) for development and 128 official test sequences (640 frames) for held-out
evaluation. Split-scoped sequence IDs distinguish e.g. train/10 from test/10.
Membership and grids were persisted before tuning. The 12 main combinations
used thresholds 3.5/4.5/5.5, smoothing 0.6/0.9 and elongation 2.5/4.0. The minimal
method used three thresholds. Selection maximized development F1, then precision,
then fixed grid order. Selected settings were written before held-out inference;
no parameters were changed in response to held-out metrics.

Selected main config: denoise_sigma=0.6, background_sigma=8, noise_sigma=12,
threshold_sigma=5.5, min_area_px=3, max_area_px=150, max_elongation=2.5,
max_candidates=200. Comparator: threshold=5.5, area=3..1000, elongation<=20,
cap=200. Main development F1=0.2156197, precision=0.1375948, recall=0.4980392.

## Limitations and next dependencies

Precision remains low despite improvement over the comparator. Star fragments,
compact stars, sensor defects and background/cloud peaks survive; faint/merged or
short-streak targets can be missed. Scores are uncalibrated, raw-image single-frame
proposals only. No registration, temporal confirmation or track evaluation exists.
Held-out results are fixed evidence, not a tuning target. Further changes require
new development/validation evidence while preserving this checkpoint.
