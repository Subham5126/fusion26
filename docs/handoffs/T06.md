## Contracts consumed / produced

- **Consumed:**
  - `app.schemas.evaluation.GroundTruthPoint` / `GroundTruthTarget` (defined evaluator-side; strictly isolated from inference).
  - Detections `list[Detection]` or Tracks `list[Track]`.
- **Produced:**
  - `app.schemas.evaluation.BenchmarkMetrics` (Schema 0.1.0).
  - Metrics computed: `precision`, `recall`, `f1_score`, `localization_rmse_px`, `id_switches`, `target_coverage`, `false_confirmed_tracks`.
  - Zero-denominator protection: Returns `None` with structured reason code in `null_reasons` dict (e.g., `"zero_predicted_points"`, `"zero_ground_truth_points"`). Never reports misleading 1.0 precision on empty negative scenes.
  - Deterministic sequence splits: `create_sequence_splits()` partitions sequence IDs into disjoint `development`, `validation`, `test` splits using SHA-256 seed hashing. For $N \ge 3$, ensures no empty split partitions.

## Reproducible sample / usage

```python
from orbittrace.evaluation import (
    GroundTruthPoint,
    evaluate_detections,
    evaluate_tracks,
    create_sequence_splits,
)

# Benchmark splits:
splits = create_sequence_splits(sequence_ids=["seq_01", "seq_02", "seq_03"], seed=42)
# {'development': ['seq_01'], 'validation': ['seq_03'], 'test': ['seq_02']}

# Evaluate detection metrics:
det_metrics = evaluate_detections(
    predictions=detections,
    ground_truth=ground_truth_points,
    matching_gate_px=5.0,
)

# Evaluate tracking metrics:
track_metrics = evaluate_tracks(
    tracks=tracks,
    ground_truth=ground_truth_points,
    matching_gate_px=5.0,
)
```

## Known limitations / notes for Lead

- Ground truth is strictly evaluator-only; no ground truth enters inference pipelines or `SequenceInput`.
- Gating defaults to 5.0 px per `docs/EVALUATION.md`.
- Requires `scipy` for Hungarian assignment (`scipy.optimize.linear_sum_assignment`).
