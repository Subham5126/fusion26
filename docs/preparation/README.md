# Preserved preparation templates

Before OrbitTrace bootstrap, the repository contained generic hackathon templates.
The root README and overlapping ARCHITECTURE/HACKATHON_PLAN documents are retained
here as `.original.md` files, byte-for-byte, including the original README's mixed
encoding footer. They are historical templates, not current setup instructions.
Their original relative links refer to the repository's original layout.

Other existing preparation files remain at their original paths, including
CONTRIBUTING, SECURITY, PRE_HACKATHON_CHECKLIST and the GitHub templates. Current
project instructions are in the root README, AGENTS and docs/STATUS.
